Vocloning Native — Privacy Policy

Last updated: November 26, 2026

1. Introduction

Vocloning Native is a native Windows application for voice cloning and text-to-speech generation. This policy explains how the application handles information when you use its core features.

2. Information processed by the application

To provide voice cloning and speech generation, the application processes audio recordings, voice reference samples, text entered by the user, locally used voice models and generated audio.

3. Local processing and storage

The core voice cloning and speech generation features process this information locally on the user's Windows device. The application does not transmit voice recordings, voice samples, voice models, text input or generated audio to the developer or to external cloud servers.

Files created or imported by the user may remain on the device until the user deletes them. Users are responsible for managing local files and protecting access to their devices.

4. Telemetry and diagnostics

The application does not automatically send usage telemetry or crash/error reports to the developer.

5. Third-party components

The application may include third-party open-source software and AI models that run locally. Their inclusion does not mean that the application's core voice data is sent to external services.

If a user independently uses another service or application alongside Vocloning Native, that service's own privacy terms apply.

6. Sharing and sale of information

The developer does not sell or share users' voice recordings, voice samples, text input, voice models or generated audio. The application does not upload these materials to the developer.

7. Children's privacy

Vocloning Native is not designed to collect personal information from children and does not require an account to use its core local features.

8. Security and user control

Because core voice processing is local, users retain control of their recordings and generated files on their devices. Users should secure their Windows accounts and devices against unauthorized access.

9. Changes to this policy

This policy may be updated if the application's features or data practices change. The latest version will be published at this address.

10. Contact

For privacy questions, contact the developer through the official Vocloning Native GitHub repository.
