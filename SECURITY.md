# Security Policy

## Supported development line

Security reports should identify the affected commit, branch, Windows version and component (application, backend, installer or third-party runtime).

## Reporting a vulnerability

Please do not publish credentials, tokens, private voice recordings or exploitable details in a public issue. Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If it is unavailable, contact the repository owner through the GitHub profile and request a private reporting channel.

## Sensitive data

Before sharing diagnostics, remove:
- Hugging Face or other access tokens.
- Authentication files and environment dumps.
- Personal user paths where unnecessary.
- Private voice references and generated audio.
- Model caches and unrelated personal files.

## Voice and model safety

Only process voice recordings for which you have permission. Do not use the application to impersonate people, deceive listeners or distribute voice recordings without authorization.
